# Домашнее задание №11 «Исключения»

## Постановка задачи

Внести изменения в домашнее задание №10. Реализовать обработку исключений. Генерировать и обрабатывать минимум три разных типа исключений, одним из которых должно быть исключение — объект класса.

## Тема программы

Программа описывает банковские счета. Используется иерархия классов:

- `BankAccount` — абстрактный родительский класс банковского счёта;
- `SavingsAccount` — сберегательный счёт с процентной ставкой;
- `PremiumAccount` — премиальный счёт с кешбэком;
- `BankClient` — клиент банка, содержащий указатель на банковский счёт.

Из домашнего задания №10 сохранены статический метод создания клиента и изменение полей вложенного счёта с помощью нисходящего приведения `dynamic_cast`.

## Реализованные исключения

### 1. `std::invalid_argument`

Генерируется статическим методом `BankClient::Create`, если передан неизвестный тип счёта.

```cpp
throw invalid_argument("Тип счёта должен быть равен 1 или 2");
```

### 2. `std::out_of_range`

Генерируется при попытке установить ставку или кешбэк меньше 0 либо больше 100 процентов.

```cpp
if (newRate < 0 || newRate > 100) {
    throw out_of_range("Ставка должна быть от 0 до 100 процентов");
}
```

### 3. `WrongAccountTypeException`

Это собственный класс исключения. Его объект генерируется, если вызвать метод, который не соответствует типу счёта. Например, попытаться изменить кешбэк у сберегательного счёта.

```cpp
class WrongAccountTypeException : public std::exception {
    // Собственный объект исключения
};
```

Все исключения обрабатываются в `main.cpp` с помощью блоков `try-catch`. После ошибки программа продолжает работу и корректно освобождает память.
