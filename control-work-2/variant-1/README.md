# Контрольная работа №2. Вариант 1 «Дерево»

## Постановка задачи

Создать иерархию из трёх классов с абстрактным родителем, двумя виртуальными
методами и статическим счётчиком объектов. Показать позднее и раннее
связывание и продемонстрировать работу методов.

## Описание программы

1. `Tree` — общий класс «Дерево». Запись `= 0` у методов `Show()` и
   `ShowWinter()` делает их чисто виртуальными, поэтому объект `Tree`
   создать нельзя. В классах `Birch` и `Spruce` оба метода реализованы со
   своими сообщениями.
2. Пользователь вводит `1` для берёзы или `2` для ели. Программа создаёт
   один выбранный объект через `new` и сохраняет его адрес в `Tree* tree`.
   При вызове `tree->Show()` и `tree->ShowWinter()` реализация выбирается
   по фактическому типу объекта. Это позднее связывание.
3. Затем создаются обычные объекты `Birch birch` и `Spruce spruce`.
   Например, `birch.Birch::Show()` явно указывает компилятору, какую
   реализацию вызвать. Это раннее связывание. Оба метода вызываются для
   каждого класса.
4. Поле `static int objectCount` общее для всей иерархии. Конструктор
   `Tree` прибавляет единицу, а деструктор вычитает. Перед удалением
   выбранного дерева созданы три объекта. После `delete tree` остаются
   два обычных объекта, которые уничтожатся при выходе из `main`.
   Виртуальный деструктор позволяет правильно удалить объект наследника
   через указатель `Tree*`.

`Tree.hpp` содержит объявления классов, `Tree.cpp` — реализацию методов,
а `main.cpp` — выбор дерева и демонстрацию.

## Сборка и запуск

Выполните команды в папке `control-work-2/variant-1`.

```bash
g++ -std=c++17 main.cpp Tree.cpp -o app
./app
```

Для проверки запустите программу дважды. При вводе `1` в блоке позднего
связывания появится берёза, а при вводе `2` — ель. Блок раннего связывания
в обоих случаях покажет оба дерева. Счётчик выведет `3`, затем `2`.
