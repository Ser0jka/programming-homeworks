## Сборка

Все программы написаны на C++. Для сборки используется стандарт C++17.

Пример:

```bash
g++ -std=c++17 main.cpp Bank.cpp -o homework
./homework
```

В домашней работе №11 приведён отдельный `README.md` с подробным описанием и командами запуска.

В репозиторий не включены отчёты, скриншоты и скомпилированные программы. Каждый проект собирается из исходных файлов на компьютере пользователя.
